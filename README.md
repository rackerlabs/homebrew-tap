# Rackerlabs Homebrew Tap

## How do I install these formulae?

`brew install rackerlabs/tap/<formula>`

Or `brew tap rackerlabs/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rackerlabs/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
